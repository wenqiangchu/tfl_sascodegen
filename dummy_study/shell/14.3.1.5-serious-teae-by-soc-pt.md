# 14.3.1.5 严重不良事件按 SOC 与 PT（Serious TEAE by SOC and PT）

## 0. 本表存在的理由

**本表不是为了回答某个临床问题，而是为了验证 `format` 驱动的层级行为。**

具体要求验证两件事：

1. **format 能提供数据中不存在的节点值。** 严重不良事件（`AESER = 'Y'`）在数据里只落在
   1 个 SOC、2 个 PT 上，共 3 例受试者。如果不做任何声明，报告只会输出这 1 个 SOC。
   通过 `levels[].format`，可以让 23 个 SOC 全部出现，其中 22 个频数为 0。
2. **父子 level 都使用 format 时，展开的是完整值域组合。** 契约规定"完整的格式化值组合
   是允许的"，因此每个 SOC 下都会长出两个 PT，即使该 SOC 一例严重事件都没有。结果是
   23 × 2 = 46 个 PT 节点，其中 44 个是"零频 SOC 下的零频 PT"。

因此本表**大量出现 `0 (0.0%)`** 是预期行为，不是错误。这是它作为 format 验证用例的
必然外观；如果以后需要一张临床上可用的严重不良事件表，应当另建，而不是修改本表。

## 3. Rows

单个 `hierarchical_summary` chunk，两层，两层都由 format 驱动：

| # | 层级 | 行/节点 | 变量 | format | 节点数 | 统计量 |
| ---: | --- | --- | --- | --- | ---: | --- |
| 1 | level 1 | SOC 节点 | `AEBODSYS` | `$tflssoc` | 23（22 个零频） | n, pct（与标签同一行） |
| 2 | level 2 | PT 节点（挂在各自 SOC 下） | `AEDECOD` | `$tflspt` | 46（44 个零频） | n, pct（与标签同一行） |

合计 **69 个报告行** = 23 SOC + 46 PT。

每人每个 SOC 只计一次、每个 PT 只计一次（`counting_unit = distinct_subject`）。

**两个 level 都声明 `format`，并因此都不声明 `label_variable` / `order_variable` /
`order_direction`。** 一个 level 要么 format 驱动、要么变量驱动，两者互斥；同时出现
是结构错误（见 `table-and-chunk-analysis-model.md` 的字段表）。

### format 定义与 `NOTSORTED`

两个 format 都定义在本表 `custom_code.before` 里，**且都带 `(NOTSORTED)`**：

```sas
proc format;
  value $tflssoc (notsorted)
    'NERVOUS SYSTEM DISORDERS' = 'Nervous system disorders'
    'CARDIAC DISORDERS'        = 'Cardiac disorders'
    ... 共 23 条 ...;
  value $tflspt (notsorted)
    'SYNCOPE'                                        = 'Syncope'
    'PARTIAL SEIZURES WITH SECONDARY GENERALISATION' = 'Partial seizures with secondary generalisation';
run;
```

`NOTSORTED` 是**必须的**，不是风格选择：

| format 定义 | 实际节点顺序 |
| --- | --- |
| 带 `(NOTSORTED)` | 声明顺序：Nervous → Cardiac → Vascular → … |
| 不带 | 原始值顺序：按 `AEBODSYS` 字符串排序，Cardiac 排第一 |

本表声明的顺序是"临床习惯顺序 + 首个 SOC 带实际数据"，所以两者肉眼可区分。
`verify/compare_with_sas.R` 的 `check_node_order()` 断言这一点：去掉 `NOTSORTED`
会让第一个 SOC 从 `Nervous system disorders` 变成 `Cardiac disorders`，验证立即失败。

## 4. Variable dictionary（本表用到的变量）

| 变量 | 标签 | 类型 | 实测取值 | 本表角色 |
| --- | --- | --- | --- | --- |
| `ADAE.TRTEMFL` | Treatment Emergent Analysis Flag | char(1) | `Y`、空 | 过滤条件 |
| `ADAE.SAFFL` | Safety Population Flag | char(1) | `Y` | 过滤条件 |
| `ADAE.AESER` | Serious Event | char(1) | `N`（1123）、`Y`（3） | 过滤条件 |
| `ADAE.TRTA` | Actual Treatment | char(20) | 3 组 | Header 列条件 |

| `ADAE.AEDECOD` | Dictionary-Derived Term | char(46) | 严重事件只有 `SYNCOPE`、`PARTIAL SEIZURES WITH SECONDARY GENERALISATION` | level 2 节点（经 `$tflspt`） |

> 事件子集。若取严重事件子集，只会有 1 个 SOC，零频节点就不存在，本表也失去验证意义。

## 5. Chunk plan

```yaml
- id: 'serious_ae_by_soc_pt'
  type: 'hierarchical_summary'
  source_data: 'study.adae'
  filter: 'SAFFL = ''Y'' and TRTEMFL = ''Y'' and AESER = ''Y'''
  levels:
    - id: 'soc'
      variable: 'AEBODSYS'
      format: '$tflssoc'      # 无 label_variable / order_variable / order_direction
      node_role: 'analysis'
      node_analysis_id: 'soc_subjects'
      missing_policy: 'exclude'
    - id: 'pt'
      variable: 'AEDECOD'
      format: '$tflspt'
      node_role: 'analysis'
      node_analysis_id: 'pt_subjects'
      missing_policy: 'exclude'
  analysis_blocks:
    - id: 'soc_subjects'
      anchor_level: 'soc'
      placement: 'same_row'
      type: 'categorical_summary_nonexclusive'
      counting_unit: 'distinct_subject'
      denominator: { scope: 'header_population', unit: 'distinct_subject' }
      rows:
        - id: 'subjects'
          type: 'analysis'
          label: 'Subjects'
          condition: '1'
          statistics: [{ id: 'n' }, { id: 'pct', digits: 1 }]
          cell_format: '{n} ({pct}%)'
    - id: 'pt_subjects'
      anchor_level: 'pt'
      placement: 'same_row'
      type: 'categorical_summary_nonexclusive'
      counting_unit: 'distinct_subject'
      denominator: { scope: 'header_population', unit: 'distinct_subject' }
      rows:
        - id: 'subjects'
          type: 'analysis'
          label: 'Subjects'
          condition: '1'
          statistics: [{ id: 'n' }, { id: 'pct', digits: 1 }]
          cell_format: '{n} ({pct}%)'
```

分页：沿用 `trt01a_header` 的 `page_rows`（默认 22），本表 69 个报告行渲染为 5 页。

## 6. Open points / 脚注

- **`label_variable` 在本表被拒绝是有意的。** format 已提供显示标签
  （`vvalue(AEBODSYS)` → `Nervous system disorders`），再写 `label_variable` 只会表达
  同一个维度的另一种写法，且无法表达 format 新增的 22 个零频 SOC。
- **顺序即行为。** 本表是 dummy study 里唯一"顺序由 format 决定"的表，其他表都用
  `order_variable` 或 `result_sort`。因此 `check_node_order()` 只对本表断言。
- **零频 PT 是父/子双 format 的直接后果。** 44 个零频 PT 来自"每个已存在父节点下展开
  完整子值域"。如果只想看到有数据的 PT，`pt` 层应改用 `order_variable`——但那会退化成
  单层 format 覆盖，不再是方案 A 的验证目标。
- P5 比对覆盖 552 个断言单元格（69 行 × 4 列 × 2 个统计量），另有 69 行的顺序断言。
- 本表**不引入** `format` 的 ranges、`OTHER`、特殊 missing、multilabel 语义；那些不在
  当前版本范围内（见 `table-and-chunk-analysis-model.md`）。
