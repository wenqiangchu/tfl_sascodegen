# 14.1.2 人口学与基线特征（Demographics and Baseline Characteristics）

## 1. Identity

| 项 | 值 |
| --- | --- |
| 表号 | 14.1.2 |
| 标题 | Demographics and Baseline Characteristics |
| 分析人群 | Intent-to-Treat（`itt`，`ITTFL = 'Y'`，254 例） |
| 来源数据集 | `adsl` |
| Header | `planned_treatment`（`TRT01P`） |
| 输出 | RTF（横版） |

本表不引用 `adadas`。参考 shell 里的 ADAS-Cog 基线来自 ADADAS（`PARAMCD='ACTOT'` 且
`ABLFL='Y'`），本 dummy study 只提交了 `adsl`/`adae`/`adlbh` 三个数据集，所以基线特征
全部取自 ADSL 的受试者级变量。若日后需要跨数据集取基线，应作为独立表型另立契约。

## 2. Columns

| 列 | 标签 | condition | 预期 N |
| --- | --- | --- | ---: |
| placebo | Placebo | `TRT01P = 'Placebo'` | 86 |
| low | Xanomeline Low Dose | `TRT01P = 'Xanomeline Low Dose'` | 84 |
| high | Xanomeline High Dose | `TRT01P = 'Xanomeline High Dose'` | 84 |

连续变量用**可用例数**作分母（每行显示自己的 `n`）；分类变量用列 N（86/84/84）作分母。

## 3. Rows

7 个 chunk：3 个 `continuous_summary` + 4 个 `categorical_summary_exclusive`。
全部 `source_data = adsl`，分类 chunk 的 `counting_unit = distinct_subject`，
`denominator = {scope: header_population, unit: distinct_subject}`。

每个 chunk 的**第一行是一个 `type: 'label'` 的 section 标题行**（不带条件、不出计数，
`indent_level = 0`），其下才是该特性的统计量行（`indent_level = 1`，在 RTF 里由
`\li200` 缩进一级）。下表把标题行与统计量行分开列：标题行自身占一行报表输出，
统计量行按 `cell_format` 各占若干行。

**缩进层级**（`indent_level × 200 twips`）：

| 行 | indent_level | 说明 |
| --- | ---: | --- |
| section 标题行 | 0 | 顶格，作为分组起点 |
| 连续型统计量行（`n`/`Mean (SD)`/`Median`/`Q1, Q3`/`Min, Max`） | 1 | 缩进一级 |
| 分类水平行（`<65`、`Female`、`White` …） | 1 | 缩进一级 |

| # | 行标签 | chunk | 类型 | 缩进 | 变量 / condition | 统计量 | 预期（P / L / H） |
| ---: | --- | --- | --- | ---: | --- | --- | --- |
| 1 | Age (years) | `age` | **label** | 0 | — | — | — |
| 2 | Body mass index (kg/m2) | `bmi` | **label** | 0 | — | — | — |

**统计量行**（每个连续 chunk 下 5 行，`source` 分别为 `AGE`/`BMIBL`/`DURDIS`）：
`n`、`Mean (SD)`、`Median`、`Q1, Q3`、`Min, Max`，各列 `n = 86 / 84 / 84`。

（预期值顺序为 Placebo / Low / High，由 `dummy_study/data` 实测，供 P4 核对。）

`cell_format`：
- 连续行：`{n} {mean} ({sd}) {median} ({q1}, {q3}) {min}, {max}`
  —— 只作演示；实际排版应在 shell 定稿时按需拆分。
- 分类行：`{n} ({pct}%)`，`pct` 取 1 位小数。

**完整性校验条件（P5 断言）**：
- 每个分类 chunk 的三行之和 = 列 N（86 / 84 / 84）：AGE 组、Sex 各自闭合；
- `RACE` 的 Placebo 列含 0 例（`AMERICAN INDIAN...`），0 必须显示为 `0 (0.0%)`
  而不是被省略——这是「行由 shell 固定，不随数据出现与否增删」的关键性质；
- `DURDSGR1` 两行之和 = 86 / 84 / 84。

> 为什么用 `categorical_summary_exclusive` 而不是 `nonexclusive`：这几组的取值互斥，
> 若同一受试者同时命中两行，`exclusive` 契约会给出重叠告警，正好用来验证该检测。

## 5. Chunk plan

```yaml
- id: 'age'
  type: 'continuous_summary'
  source_data: 'study.adsl'
  counting_unit: 'distinct_subject'
  analysis_variable: 'AGE'
  rows:
    - id: 'age_row'
      type: 'analysis'
      label: 'Age (years)'
      statistics:
        - id: 'n'
        - id: 'mean'
          digits: 1
        - id: 'sd'
          digits: 2
        - id: 'median'
          digits: 1
        - id: 'q1'
          digits: 1
        - id: 'q3'
          digits: 1
        - id: 'min'
          digits: 1
        - id: 'max'
          digits: 1
      cell_format: '{n} {mean} ({sd}) {median} ({q1}, {q3}) {min}, {max}'
- id: 'agegr'
  type: 'categorical_summary_exclusive'
  source_data: 'study.adsl'
  counting_unit: 'distinct_subject'
  denominator:
    scope: 'header_population'
    unit: 'distinct_subject'
  rows:
    - id: 'agegr_lt65'
      type: 'analysis'
      label: '<65'
      condition: 'AGEGR1 = ''<65'''
      statistics:
        - id: 'n'
        - id: 'pct'
          digits: 1
      cell_format: '{n} ({pct}%)'
    # 65-80 与 >80 同构，略
```

## 6. Open points / 脚注

- 分位数（`median`/`q1`/`q3`）在 P5 比对时**只报告不判定**，因为 SAS `PCTLDEF` 与 R
  `quantile(type=)` 的定义差异会让它们系统性偏移；`n`/`mean`/`sd`/`min`/`max` 必须一致。
- 小节的 label 行（第 4、8、11、15 行）是 `label` 类型行，不参与统计；它们让 shell 的
  结构与参考 shell 的缩进一致。
- 参考 shell 还包含 MMSE、ADAS-Cog 等参数，本表未覆盖——它们要么来自 ADADAS，
  要么属于其他表型。
